# 阶段 3：概要设计

**技能**：`hld-design` ｜ **产出**：`docs/*概要设计*.md`

## 做什么
从 SRS 推导系统总体架构：分层、模块划分、模块间依赖与调用关系、技术选型、部署拓扑、
非功能设计（性能/安全/可用性/日志监控）。

## 要点
- **技术选型在这一阶段定死**：阶段 7 走深度档时，`dev-fullstack-product` 的阶段 1 技术栈确认
  应当**读本文档已定的选型**，只补它没覆盖的项，不要推翻重选
- 架构图、部署图、模块依赖图一律走 `diagram-generator`
- 老项目架构既定 → 用 `hld-design` 的**反向同步模式**从代码补文档

## 门禁（进阶段 4 前）
- [ ] 模块划分清晰，每个模块的职责边界写明
- [ ] 技术选型每项带版本号（不写 `latest`）
- [ ] 与 SRS 的非功能需求逐条对应

## 可并行
可与阶段 2 并行。
