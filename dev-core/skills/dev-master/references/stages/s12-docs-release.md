# 阶段 12：文档与发版

**技能**：`pm-operation-manual` + `pm-release-notes` + `finishing-branch`
**产出**：`dev/release/`（手册 · 发版说明；`CHANGELOG.md` 仍在仓库根）

## 做什么
1. **操作手册** `pm-operation-manual`：基于 SRS 与已实现页面生成管理员手册 / 终端用户指南
2. **发版说明** `pm-release-notes`：本次变更、新增功能、修复、已知问题、升级注意事项
3. **分支收尾** `finishing-branch`：验证测试 → 检测环境 → merge / PR / 保留 / 丢弃 四选一

## Word 导出的三个坑（踩过的）
- **导出读的是启动那一刻的 md**：任何编辑之后都要重新导出，否则 docx 静默过期 → **导出永远放最后**
- **图片文件名含中文会静默丢图**：导出后必须验 `unzip -l x.docx | grep -c 'word/media/'`，数字等于图片张数
- 改过文案的图必须**重渲**：源文件与图片 mtime 对不上就是过期图
