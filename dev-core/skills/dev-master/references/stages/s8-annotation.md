# 阶段 8：原型标注

**技能**：`annotation` ｜ **产出**：页面内标注层

## 做什么
在已实现的页面上注入需求标注（字段说明、业务规则、交互逻辑、数据来源），
开发和产品都能看到。标注与 UI 库解耦，通过注入专属 class 定位。

## 要点
- 标注内容的**唯一来源是 SRS**，不要临场编业务规则
- 交付给甲方评审、或多人协作接手时价值最大；内部单人项目可跳过
- 标注注入后不应影响生产构建（确认是开发态开关或独立 entry）

## 可跳过
不需要给评审/开发看需求标注 → 跳过。

## 门禁（进阶段 9 前）
- [ ] 标注内容逐条能在 SRS 里找到出处（找不到的标「待确认」，不要临场编业务规则）
- [ ] 标注注入不影响生产构建（确认是开发态开关或独立 entry）
- [ ] 页面仍能正常跑起来（注入后起一次服务）
