# 阶段 10：调试与验收

**技能**：`verification-before-completion`（终检）+ `systematic-debugging`（有具体故障时）

## 做什么
1. **有缺陷** → `systematic-debugging`：复现 → 缩小范围 → 定位根因 → 修 → 验证 → 回归
   （**禁止猜着改**：没复现就别提交修复）
2. **无缺陷** → `verification-before-completion`：逐条核对「说做完的事是不是真做完了」
   —— 命令真跑过没有、产出文件真存在没有、报告里的结论有没有证据
