# 阶段 4：详细设计

**技能**：`lld-design` ｜ **产出**：`dev/design/*详细设计*.md`（模块 + 数据库 + API 三合一；落盘路径显式传给它）

## 做什么
一份文档覆盖三个维度：
1. **模块详细设计**：类图/职责/关键流程时序
2. **数据库物理设计**：表结构、字段类型、索引、约束、初始化与迁移脚本规划
3. **API 详细设计**：路径、方法、入参出参、错误码、鉴权要求、限流

## 要点
- 这是阶段 7 能不能一次写对的分水岭：**字段、校验、枚举、状态流转要在这里定死**
- 统一响应体与错误码表在这一阶段成文（`dev/design/error-codes.md`）
- 不要拆成三份文档——三合一是本技能的设计

## 门禁（进阶段 5/7 前）
- [ ] 每个 SRS 字段级规格都能在表结构或接口里找到落点
- [ ] 每个接口标了鉴权要求与数据范围（RBAC 的「数据可见性」不能只写在需求里）
- [ ] ER 图、时序图由 `diagram-generator` 生成

## 确认节点
标准/严格模式**必停**——这是返工成本最高的一份文档。
