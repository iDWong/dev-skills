# 阶段 5：交付规划

**技能**：`delivery-plan` ｜ **产出**：`docs/delivery-plan-{项目名}.md`

## 做什么
把功能清单排成可执行的实现顺序：模块依赖拓扑、三端推进方式（纵向打通 / 横向分层）、
每个功能的状态位（待办/进行中/已完成）、下一步推荐。

## 要点
- `delivery-plan` 自带**进度追踪**与**自动连跑模式**：用户说「按计划实现所有功能」时由它驱动阶段 7
- 三端项目默认**纵向打通**：一个模块的后端 → 管理端 → 移动端全部跑通，再开下一个模块
- 排序原则：认证/权限这类被依赖的模块永远排最前

## 门禁（进阶段 7 前）
- [ ] 每个功能项都有所属模块与顺序号
- [ ] 依赖关系无环
- [ ] 状态位初始化完毕（阶段 7 每完成一项要回写）

## 可跳过
功能少于 ~5 个且顺序显而易见 → 跳过，在进度存档里直接写实现顺序。
